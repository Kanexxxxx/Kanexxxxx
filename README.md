## Projetos em destaque

### [Karol — site e agendamento](https://github.com/Kanexxxxx/Karol)

Site e agenda para atendimento com hora marcada, com painel administrativo e integração de mensagens. A separação entre atendimento automático e operações confirmadas na agenda é uma das decisões centrais do projeto.

**Next.js · TypeScript · React · Supabase**
Estado: aplicação em evolução; integrações exigem configuração própria.

### [Vitraya Studio — operação de ofertas](https://github.com/Kanexxxxx/Vitraya)

Aplicativo local para organizar produtos de afiliados, importar catálogos com imagens, criar artes e preparar publicações. O catálogo usa SQLite; conectores externos possuem configuração e limites próprios.

**React · Vite · Node.js · SQLite**
Estado: desenvolvimento local, com frentes de integração em revisão.

### [Nexakeep — sites e agendamento por loja](https://github.com/Kanexxxxx/projeto-pessoal/tree/implementacao)

Aplicação para sites de pequenos negócios e agendamento, com autenticação e separação de dados por loja. A implementação está na branch **implementacao**; a branch principal preserva o planejamento inicial.

**Next.js · TypeScript · PostgreSQL · Better Auth**
Estado: implementação local; a documentação identifica funcionalidades e pendências.
